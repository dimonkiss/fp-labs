Степінь многочлена n: 4
Коефіцієнти (a0 a1 ... an) у вигляді списку: (1 0 0 0 4)

Многочлен:  P(x) = x^4 + 4
Розкладання: P(x) = (x^2 - 2x + 2)(x^2 + 2x + 2)
Лінійних множників (з кратністю): 0
Нерозкладні множники степеня >= 2: 2  →  (x^2 - 2x + 2)(x^2 + 2x + 2)
Перевірка (добуток множників): x^4 + 4
Розкладання ПРАВИЛЬНЕ — добуток множників збігається з вихідним многочленом
