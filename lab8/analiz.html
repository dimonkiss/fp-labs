Задача 8.1: Розкладання многочлена на множники

Подання многочлена

Многочлен P(x) = a0xn + … + an з цілими коефіцієнтами подається списком (a0 a1 … an) від старшого коефіцієнта до вільного члена; степінь n вводиться окремо й перевіряється (довжина списку = n + 1, a0 ≠ 0).

Правила алгебри, що використано

  1. Винесення спільного множника. g = НОД усіх коефіцієнтів (зі знаком старшого), P = g·P0, де P0 — примітивний многочлен (НОД коефіцієнтів = 1) із додатним старшим коефіцієнтом.
  2. Винесення степеня x. Якщо k молодших коефіцієнтів нульові, P = xk·P′.
  3. Теорема про раціональні корені. Якщо p/q (нескоротний) — корінь многочлена з цілими коефіцієнтами, то p ділить вільний член an, а q ділить старший коефіцієнт a0. Кандидати ±p/q перебираються (all-candidates), корені перевіряються схемою Горнера (poly-eval).
  4. Ділення на (x − r) за схемою Горнера (divide-by-root, synthetic). Корінь r = p/q дає лінійний множник (qx − p) = q·(x − r). За лемою Гаусса частка від ділення примітивного многочлена на примітивний множник (qx − p) має цілі коефіцієнти, тому try-root ділить частку на q — і працює далі з цілими числами. Процес повторюється, поки знаходяться корені — так враховується кратність.
  5. Залишок без раціональних коренів. Для многочленів виду ax⁴ + bx² + c застосовано два правила: (а) дискримінант b² − 4ac — повний квадрат ⇒ ax⁴ + bx² + c = a(x² − y₁)(x² − y₂); (б) різниця квадратів: якщо a = r², c = s², t² = 2rs − b, то ax⁴ + bx² + c = (rx² − tx + s)(rx² + tx + s) (наприклад, тотожність Софі Жермен x⁴ + 4 = (x² − 2x + 2)(x² + 2x + 2)). Інші залишки виводяться як нерозкладні над ℚ.

Перевірка розкладання

Окрема процедура verify перемножує всі множники (g, xk, лінійні, нелінійні) — expand, poly* — і порівнює коефіцієнти з вихідним многочленом (poly=?); при збігу виводиться «розкладання ПРАВИЛЬНЕ».

Запис результатів

Результат виводиться на екран і дублюється у файл factorization.txt через спільну процедуру emit-lines.

Межі застосування

Над полем ℚ многочлен розкладається повністю лише з урахуванням усіх нерозкладних множників; програма гарантує повний розклад для многочленів степеня ≤ 3 і виду ax⁴ + bx² + c; для довільних многочленів вищих степенів без раціональних коренів залишок може бути розкладним на квадратичні множники (потрібен алгоритм Кронекера чи Ценхауза) — такий залишок виводиться як окремий множник.
