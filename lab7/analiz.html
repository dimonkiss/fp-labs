Задача 7.1: Текстові файли: заміна слова

План програми

  1. Генерація тексту. Кожен рядок складається з чотирьох частин «підмет — дієслово — додаток — закінчення», кожна обирається зі свого списку за значенням ЛКГ (s′ = (s·1103515245 + 12345) mod 231, індекс = (s′ div 65536) mod довжина). Результат відтворюється за seed.
  2. Запис у файл. call-with-output-file + рекурсивний вивід рядків (write-lines): display у порт, newline.
  3. Читання. call-with-input-file; read-lines читає символи read-char і збирає рядок у зворотний список символів; при # ewline рядок завершується; стандартний R5RS не має read-line, тому процедура написана власноруч.
  4. Заміна слова. Скінченний автомат із двома станами «усередині слова» / «поза словом»: літери (char-alphabetic?) накопичуються у слові, на першому нелітерному символі слово порівнюється з цільовим (без урахування регістру); якщо збіглося — у результат записується нове слово, інакше — старе; знаки пунктуації переносяться без змін. Складність O(L) за довжиною тексту.
  5. Запис результату в новий файл і перевірка кількості рядків.

Особливості

Слово визначається як максимальна послідовність літер, тому «програмування» не замінюється всередині «програмувати» (інша словоформа) і не залежить від регістру («Програмування» → «код»). Це підтверджено тестами (збіг із регулярним виразом Python).

Задача 7.2: Тональність тексту

Конвеєр аналізу

  1. Зчитування: файл → список рядків.
  2. Токенізація й нормалізація: кожний рядок розбивається на слова за нелітерними символами; літери переводяться у нижній регістр (char-downcase), пунктуація відкидається.
  3. Стоп-слова: (filter (lambda (w) (not (member w stop-words))) words). Слова «не», «ні», «дуже» навмисно не є стоп-словами, бо несуть інформацію про тональність.
  4. Словник емоцій: асоціативний список слово → вага (позитивні: «гарний» +1, «чудовий» +2 …; негативні: «поганий» −1, «жахливий» −2 …); підсилювачі: «дуже» ×1,5, «надзвичайно» ×2, «сильно» ×1,5, «вкрай» ×2; заперечення «не», «ні» змінюють знак.
  5. Оцінка слів: проходом по списку зберігається поточний множник mult (добуток підсилювачів) і знак neg (±1). Для емоційного слова з вагою w додається mult·neg·w, лічильник N збільшується, mult і neg скидаються. Будь-яке інше слово також скидає їх (дія модифікатора — на найближче наступне емоційне слово).
  6. Нормалізація: T = S / N (середня вага емоційного слова; якщо N = 0, T = 0).
  7. Інтерпретація: T > 0,2 — позитивний; T < −0,2 — негативний; інакше нейтральний.
T = Σi mi · ni · wi / N

Приклад: «Це дуже гарний фільм» → стоп-слово «це» видаляється; «дуже» дає mult = 1,5; «гарний» (w = 1) → 1,5; N = 1; T = 1,5 — позитивний. «Це не гарний фільм» → neg = −1 → T = −1 — негативний.

Обмеження

Метод словниковий: без лематизації (потрібні словоформи зі словника), без розуміння іронії й контексту; слова поза словником не впливають. Ці обмеження типові для простих NLP-систем і задокументовані.
