Файли для Dr.Racket (вже мають першим рядком #lang). Як користуватись:
1. Відкрийте файл у Dr.Racket (File → Open).
2. Натисніть Run (зелена стрілка / F5) — програма сама запустить (main).
3. Вводьте дані у нижньому вікні (Interactions), коли програма їх просить.

lab1…lab6 — мова r5rs (крім lab1_task1_ackermann.rkt — там #lang racket через вимірювання часу);
lab7, lab8 — мова racket. lab1_compare_time.rkt — порівняння часу виконання.
Файли review_*.txt у lab7 мають лежати поруч із програмою.
